Background & Objectives

The development of information technology has increased the need for reliable digital systems in tourism. The Assistentour website serves as an information and booking platform. To ensure quality, we applied the Software Testing Life Cycle (STLC) to validate all core features before release.

Objectives:

  • Verify if all website features function correctly
  • Identify errors or bugs in the system
  • Ensure Login, Booking, Destination, Category, and User modules work as expected
  • Measure system success rate based on test case results
  • Provide recommendations for failed features

Testing Scope

DashboardBooking Status ChartLatest Bookings Destination CRUDBooking ManagementBooking Report Export User ManagementCategory Management Login/LogoutDark Mode Toggle

STLC Phases Applied

  1. Requirement Gathering: Analyzed Assistentour website structure, user flows, and functional requirements.
  2. Test Planning: Defined scope, strategy, schedule, resources, and exit criteria.
  3. Test Case Development: Created 28 test cases with Test Steps, Input, Expected and Actual Results.
  4. Test Environment Setup: Configured Chrome, Firefox, and Selenium for execution.
  5. Test Execution: Ran all test cases using Selenium and documented results.
  6. Test Cycle Closure: Analyzed results, identified bugs, and prepared final report.

Conclusion

Based on the STLC testing of the Assistentour website, 23 out of 28 test cases passed. Core modules such as Dashboard, Booking, Login, and Dark Mode function correctly. However, 5 high-severity bugs were found related to CRUD action buttons. We recommend fixing these issues and performing regression testing before production release.
