Background

The development of information technology has increased the need for reliable digital systems, especially in the tourism sector. Modern tourists rely on websites for destination information, location maps, and recommendations. To ensure optimal service, tourism websites must undergo systematic testing to ensure they are error-free and ready for use.

The Assistentour website was developed as a tourism information media. This project applies the Software Testing Life Cycle (STLC) method to ensure system quality before release.

Testing Scope

DashboardDestinationsBooking Booking ReportUser ManagementCategory Login/LogoutDark Mode

STLC Methodology

  1. Requirement Gathering: Identify functional needs of Assistentour website
  2. Test Planning: Define strategy, schedule, and resources
  3. Test Case Development: Create test scenarios with Selenium
  4. Test Environment Setup: Chrome, Firefox, Selenium
  5. Test Execution: Run test cases and record results
  6. Test Cycle Closure: Evaluate results and bug analysis
