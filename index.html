Background & Objectives

Assistentour serves as an information and booking platform for tourism. To ensure quality, we applied STLC to validate all core features before release. Objectives: verify all features function correctly, identify errors, ensure Login, Booking, Destination, Category, and User modules work as expected, measure success rate, and provide recommendations for failed features.

STLC Phases Applied

How testing was executed.

1. Requirement Gathering: Analyzed Assistentour structure, user flows, functional requirements.
2. Test Planning: Defined scope, strategy, schedule, resources, exit criteria.
3. Test Case Development: Created 28 test cases with Steps, Input, Expected & Actual.
4. Environment Setup: Configured Chrome, Firefox, Selenium.
5. Test Execution: Ran all test cases, documented results.
6. Test Cycle Closure: Analyzed results, identified bugs, prepared final report.

Conclusion

Based on STLC testing of Assistentour, 23 out of 28 test cases passed. Core modules such as Dashboard, Booking, Login, and Dark Mode function correctly. However, 5 high-severity bugs were found related to CRUD action buttons. We recommend fixing these issues and performing regression testing before production release.
